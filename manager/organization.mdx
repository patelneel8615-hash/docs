## General Configuration

#### **Currency**

The currency you select here will be used throughout the website for all financial transactions and reports. It ensures consistency in how amounts are displayed and calculated.

#### **General Audit Clearance Period (Days):** 

Set the number of days after that general audit logs will be cleared.

#### **Leave Audit Clearance Period (Days):** 

Set the number of days after that leave audit logs will be cleared.

#### **Maximum Depth Level for Fetching Employee Reportee Hierarchy:** 

Set the maximum number of reporting levels to retrieve when displaying an employee's reporting hierarchy.<br />

### **Employee Configuration**

- Upcoming Birthday Reminder (Days): 

Set the number of days in advance to notify users about upcoming employee birthdays.

- Employee Activation Token Expiry (Minutes): 

When a new employee is added, they receive an activation email to set up their account. This setting defines how long the activation link remains valid.<br />By default, this value is set to _10 minutes_. You can adjust it to a longer or shorter period depending on your company’s security preferences. Click **Save** to update the expiry time.

_After this time elapses, the activation link expires, and the employee will need to request a new activation email._

- Upcoming Anniversary Reminder (Days): 

Set the number of days in advance to notify users about upcoming employee work anniversaries.

- Employee Resignation Request Identifier Prefix: 

Set the prefix used to identify employee resignation requests.

- Upcoming Leave Reminder (Days): 

Set the number of days in advance to notify users about upcoming approved employee leave.<br />
